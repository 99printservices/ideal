# Ideal Solutions Group

Site estático completo: HTML, CSS, JavaScript e imagens locais.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Envie index.html, a pasta assets e .nojekyll para a raiz do repositório.
3. No GitHub, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch, branch main e pasta / (root). Salve.

Os caminhos das imagens são relativos e funcionam em sites de projeto do GitHub Pages. Não é necessário instalar pacotes ou executar um build.
